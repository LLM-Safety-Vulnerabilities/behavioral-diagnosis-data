# 大语言模型安全脆弱性：机理化评测与行为诊断

本仓库提供论文《大语言模型安全脆弱性：机理化评测与行为诊断》的代表性数据子集，覆盖六类脆弱性机理对应的14个风险场景，并包含基础风险种子及其语义匹配无害对照。

## 数据概况

当前版本共 **16个 JSONL 文件、640条样本**。其中，14个风险场景共560个评估单元，另有基础风险种子与语义匹配无害对照各40条。

| 脆弱性机理 | 风险场景 |
| --- | --- |
| M1 风险意图判别失稳 | 语义变换、情境包装 |
| M2 上下文安全约束保持失稳 | 长上下文干扰、指令冲突、多轮交互 |
| M3 分步推理安全执行失稳 | 任务分解、分步执行 |
| M4 表层—实质一致性失稳 | 表层合规测试、字面约束测试 |
| M5 专业场景泛化失稳 | 法律任务、代码任务、医疗任务 |
| M6 模拟外部内容与权限条件下的控制失稳 | 模拟权限边界、模拟外部内容冲突 |

## 数据构造与评测说明

场景化评估数据按上述脆弱性机理与风险场景组织，提供测试输入及相应的参考答案或判定条件，供理解各类场景的数据组织与典型输入形式。

相关方法与实验设置已在论文正文和附录中说明，包括：

- **数据构造**：基础风险种子、攻击与输入扰动方法，以及专业任务和模拟条件场景的构造方式。
- **筛选与标注**：样本筛选流程、语义去重、风险场景定义及场景分类提示词。
- **评测设置**：模型调用与部署设置、指标判别提示词，以及参考答案和判定依据。
- **指标计算**：19项场景化指标的定义、归一化方法，以及场景内与机理内的两级聚合方式。

可结合公开样本与论文所述流程构建相应测试数据，开展同口径评测与行为诊断。

## 获取与引用

数据以 JSONL 格式保存，每行对应一条样本。可直接查看各数据文件，或通过仓库首页的 **Code → Download ZIP** 下载全部文件。

如使用本仓库数据，请引用论文《大语言模型安全脆弱性：机理化评测与行为诊断》，并注明所使用的数据版本。

## 内容提示与研究用途

本数据集面向大语言模型安全评测、行为诊断及风险缓解研究。部分样本包含有害请求、对抗性表达、冒犯性语言或其他敏感内容，可能引起不适。相关内容作为安全评测材料呈现，不代表作者观点或行为建议。
